# Agent development tools

This directory records optional agent skills and MCP tools evaluated for
developing the project. These tools run only on writable Debian or a development
workstation. They are never copied into the Buildroot appliance unless a
specific runtime component is independently justified.

See `catalog.md` for candidates and research gaps. Inclusion in the catalog is
not approval to install or vendor code. Before adoption, verify the exact
revision, license, dependencies, security boundary and a project-relevant smoke
test.
