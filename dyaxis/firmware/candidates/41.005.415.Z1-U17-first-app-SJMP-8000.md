# First U17 external-application validation image

This is a deliberately minimal derived test image. It is not an original
Studer/Editech firmware image.

## Source and image

- Source: `41.005.415.Z1-U17-first-app-SJMP-8000.asm`
- Payload bytes at CPU CODE `0x8000`: `80 FE`
- Instruction: 8051 `SJMP $`
- Intended behavior: remain at the external application entry point after
  U17 executes `LCALL 0x8000`
- Peripheral operations: none
- Complete image size: 32,768 bytes
- Candidate SHA-256: `cb5a4306ce73bef3b6ec76b18b367606d1a954e99d6584350c6b7ef394c9ee19`

The image was built with `dyaxis/analysis/u17_image.py` using the verified
original DS1230 dump as the protected-region template. Bytes `0x0002–0x7DFB`
are zero; signature `AA 55` is at `0x7DFC–0x7DFD`; the complemented
big-endian checksum is `FDD7` at `0x7DFE–0x7DFF`; bytes `0x7E00–0x7FFF` are
unchanged from the original canonical DS1230 image.

This record proves programming and readback integrity. It does not claim that
the application has executed in the console until the DS1230 is reinstalled
in its original orientation and the board is powered.
